HTML — HyperText Markup Language

HTML es el lenguaje de marcado que define la estructura y contenido de una página web. No es un lenguaje de programación; es un lenguaje descriptivo que usa etiquetas para indicar qué tipo de contenido hay en cada sección.

Todo documento HTML tiene una estructura base con <!DOCTYPE html>, <html>, <head> y <body>. Lo que va en el body es lo que el usuario ve en el navegador.

  • Las etiquetas HTML se escriben entre corchetes angulares: <p>
  • La mayoría tienen apertura y cierre: <div>...</div>
  • Los atributos añaden información extra: href="url", src="imagen.jpg"
  • HTML5 introdujo etiquetas semánticas: <header>, <nav>, <footer>
  • Los formularios (<form>) permiten recibir datos del usuario
index.html 
<!-- Estructura base de un documento HTML -->
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi Página Web</title>
</head>

<body>

  <!-- Encabezados del h1 (mayor) al h6 (menor) -->
  <h1>Título Principal</h1>
  <h2>Subtítulo</h2>

  <!-- Párrafo de texto -->
  <p>Esto es un párrafo de texto.</p>

  <!-- Enlace (hipervínculo) -->
  <a href="https://google.com">Ir a Google</a>

  <!-- Imagen -->
  <img src="foto.jpg" alt="Descripción">

  <!-- Lista no ordenada -->
  <ul>
    <li>Elemento 1</li>
    <li>Elemento 2</li>
  </ul>

</body>
</html>

CSS — Cascading Style Sheets

CSS controla cómo se ve el HTML: colores, fuentes, tamaños, espaciados, posicionamiento y animaciones. La "cascada" significa que los estilos más específicos sobrescriben a los más generales.

CSS puede aplicarse de 3 formas: inline (style=""), interno (<style>) o externo (archivo .css). El externo es la mejor práctica en proyectos reales.

  • Selector: elige qué elemento(s) estilar (p, .clase, #id)
  • Propiedad: qué aspecto cambiar (color, font-size, margin)
  • Valor: el nuevo valor de la propiedad (red, 16px, auto)
  • Flexbox: sistema para alinear elementos en una dirección
  • Grid: sistema para crear layouts bidimensionales (filas y columnas)
styles.css 
/* Variables CSS (Custom Properties) */
:root {
  --color-primario: #00ff88;
  --fuente-base:  'Arial', sans-serif;
}

/* Selector de etiqueta — aplica a todos los <body> */
body {
  font-family: var(--fuente-base);
  background: #0a0a0f;
  color:       #f0f0f5;
  margin:      0;
}

/* Selector de clase — el punto "." indica clase */
.tarjeta {
  background:    #111118;
  border-radius: 16px;   /* Esquinas redondeadas */
  padding:       1.5rem; /* Espacio interior */
  margin:        1rem 0; /* Espacio exterior */
}

/* Flexbox — alinea hijos en fila */
.contenedor {
  display:         flex;
  align-items:    center;     /* Centrado vertical */
  justify-content: space-between; /* Espacio entre */
  gap:             1rem;
}

/* Animación CSS */
@keyframes aparecer {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

.animado {
  animation: aparecer 0.6s ease;
}

JavaScript — El Lenguaje de la Web

JavaScript (JS) da comportamiento e interactividad a las páginas web. Es el único lenguaje que los navegadores entienden de forma nativa para la parte del cliente (frontend).

Con JavaScript puedes responder a clics del usuario, modificar el HTML en tiempo real (DOM manipulation), hacer peticiones a servidores (fetch/AJAX) y crear aplicaciones web completas.

  • let / const declaran variables (var es antigua)
  • Las funciones son bloques de código reutilizables
  • Los arrays ([]) guardan listas de elementos
  • Los objetos ({}) guardan pares clave-valor
  • El DOM permite modificar el HTML desde JavaScript
script.js 
// ── VARIABLES ──────────────────────────────
const nombre = "Ana";     // no se puede reasignar
let   edad   = 25;       // sí se puede reasignar

// ── FUNCIONES ───────────────────────────────
function sumar(a, b) {
  return a + b;
}

// Arrow function (ES6) — más corta
const multiplicar = (a, b) => a * b;

// ── ARRAYS ──────────────────────────────────
const lenguajes = ["HTML", "CSS", "JS", "C++"];
lenguajes.forEach(lang => {
  console.log(`Aprendiendo: ${lang}`);
});

// ── OBJETOS ─────────────────────────────────
const estudiante = {
  nombre: "Ana",
  edad:   25,
  saludar() {
    return `Hola, soy ${this.nombre}`;
  }
};

// ── MANIPULACIÓN DEL DOM ────────────────────
// Seleccionar elemento por ID
const btn = document.getElementById("miBoton");

// Añadir evento al botón
btn.addEventListener("click", () => {
  document.getElementById("resultado").textContent
    = "¡Botón clickeado!";
});

// ── FETCH API (peticiones HTTP) ─────────────
async function obtenerDatos() {
  const respuesta = await fetch("https://api.ejemplo.com");
  const datos     = await respuesta.json();
  console.log(datos);
}

C++ — Programación de Alto Rendimiento

C++ es un lenguaje compilado de propósito general que combina programación orientada a objetos con control de bajo nivel del hardware. Se usa en videojuegos, sistemas operativos, motores gráficos y aplicaciones críticas.

A diferencia de JavaScript, C++ requiere ser compilado antes de ejecutarse. El programador gestiona la memoria manualmente con punteros, lo que da más control pero también más responsabilidad.

  • #include importa librerías (similar a import en JS)
  • Las variables tienen tipos estrictos: int, float, string
  • Los punteros guardan direcciones de memoria (int* ptr)
  • Las clases son plantillas de objetos (OOP)
  • cout imprime en consola; cin lee entrada del usuario
main.cpp 
// Incluir librerías estándar
#include <iostream>  // Para cout y cin
#include <string>    // Para usar string
#include <vector>    // Para usar vector (array dinámico)

using namespace std;  // Evita escribir "std::" cada vez

// ── CLASE (Programación Orientada a Objetos) ─
class Estudiante {
private:            // Solo accesible dentro de la clase
  string nombre;
  int edad;

public:             // Accesible desde fuera
  // Constructor — se llama al crear el objeto
  Estudiante(string n, int e) : nombre(n), edad(e) {}

  // Método — función dentro de la clase
  void saludar() {
    cout << "Hola, soy " << nombre
         << " y tengo " << edad
         << " años." << endl;
  }
};

// ── FUNCIÓN PRINCIPAL ──────────────────────
int main() {
  // Crear objeto de la clase Estudiante
  Estudiante e1("Ana", 25);
  e1.saludar();

  // Vector (array dinámico)
  vector<string> lenguajes = {"HTML", "CSS", "C++"};

  // Bucle for moderno (range-based)
  for (const string& lang : lenguajes) {
    cout << lang << endl;
  }

  return 0; // Indica que el programa terminó bien
}
